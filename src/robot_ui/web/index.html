Basler preview

The Basler is kept closed between captures (heat, sensor life, and the VISION lamp must only be lit while the shutter is open). Preview asks basler_camera_node to hold it open and polls the capture service; "VISION lamp" holds the lamp on for aiming and is released automatically when the camera closes. The UI never opens the device or drives the lamp itself.

Task command

Tasks are the path-data files in task/csv, as task_executor reports them on /task_list: assigned_workpoints_* (end-effector poses) → scan_pose_*, rrt_final_path_* (joint angles) → scan_joint_*. A task never returns to the start tag on its own — "scan then come back" is two commands. Send TASK go_home separately.

Ra data collection (hand roughness tester)

For the Ra model's training set: frames from the real scan TASK paired with a hand roughness tester's reading at the same spot. Two methods, pick one in Mode. pause (method A): every N scanned points the tool retreats 80 mm along its z and waits; the table lists the N points with each earlier point's offset from the tip (the last point is directly under the vision tip), so two testers measure in parallel; type each reading (several separated by spaces → their mean), tick skip for a point you could not measure, Record & next — the arm returns to the captured pose and goes on. With mark spot before retreat on, every scanned point first stops at the standoff (tool NOT retreated, case bottom 16.5 mm up): draw a dot or the case outline beside the case — the spot is under the case centre — and press Next; the retreat + Ra entry stop follows as above. mark (method B): NO capture — every scanned point stops at the standoff (retreated 30 mm) for you to write the shown number beside the spot (outside the camera's few-mm field) and press Next; the run writes results/scan_images/<run>/<run>_mark_template.csv (number → group / point / x y z, blank ra_measured). Measure all marks afterwards in any order with any number of testers, fill the column in, run the same TASK normally for the frames, then merge_ra_dataset.py <scan run> --measured <filled template>. Cancel arm motion / STOP ALL during a wait ends the scan with the tool left retreated. Works from a phone on the LAN.

Lift

Reach a scan height by lift origin homing and then climbing — the drive has backlash, so a height reached by descending is not the same physical position. Absolute moves are refused before origin homing.

Manual move (odometry-closed, no tag)

Drives the base a fixed distance or pivots a fixed angle through mobile_node (/mobile/move_cmd) — trapezoid profile, closed on /odom, aborts if odom stalls. Refused while a GOTO/TASK or a calibration session is driving. After STOP ALL the base is emergency-latched: press "Clear stop latch" before the next move.
